01 / Overview

About the project.

An AI-powered smart hiring system combining LLaMA 3.2, retrieval-augmented generation, and NLP for context-aware candidate evaluation.

Context

The problem.

Bring relevant candidate information into an AI-assisted hiring workflow so evaluations can use retrieved context alongside language-model responses.

03 / Technology

How it comes together.

StellarisAI combines retrieval-augmented generation, NLP, and LLaMA 3.2 for candidate evaluation. Flask REST APIs connect these capabilities to the recruitment workflow.

The technical focus is connecting retrieved context with a language model, then making that workflow usable through backend APIs. The project brings prompt engineering and application development into the same system.
