03 / Technology

How it comes together.

The project connects neurological data preprocessing and deep learning analysis with a Python API layer. PyTorch supports the modelling work, while asynchronous FastAPI endpoints expose the analysis workflow.

The engineering work spans two connected concerns: preparing neurological data for modelling, and exposing inference through an asynchronous backend. Docker is part of the documented development stack.
